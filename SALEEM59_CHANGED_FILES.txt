SaleeM v3.41.0 – trader-first portrait result

Modified files:
- app/__init__.py
- app/main.py
- app/engine/renderer.py

Key changes:
1) Added a large top decision card that answers: enter now, wait for activation, or do not enter.
2) Shows Entry, Stop, TP1 and reading strength in the top card.
3) Uses a compact scenario zone near the latest candles instead of covering the chart.
4) Added 5 projected candles along the expected path.
5) Shows Entry/Stop/TP prices as colored text aligned on the spare right margin.
6) Support/resistance remain thin background lines with compact aligned prices.
7) BOS/CHOCH/IDM are secondary; IDM is hidden when it would overlap important labels.
8) Kept the portrait-only workflow and Reset Vertical Scale requirement.

=== v3.41.1 ===
- Corrected IDM placement to use the latest real internal counter-trend swing before BOS.
- BOS / CHOCH / IDM are always shown when structure data is available.
- Increased structure marker circle size slightly and strengthened the line/text for readability.
- Structure side-lines automatically reverse direction when the preferred side is crowded or overlaps the right-side trade area.


=== v3.41.3 ===
- Corrected BOS / CHOCH / IDM visual placement for the portrait result.
- BOS/CHOCH/IDM markers are clamped inside the chart and can no longer be clipped at the top/bottom.
- Structure leader lines now score both text and line congestion and flip to the opposite side when crowded.
- Increased structure anchor-circle size slightly while keeping labels secondary/small.
- IDM now uses only a real recent internal swing in the 8–12 candle window before BOS; if no valid swing exists, IDM is omitted instead of using an old distant level.
- Limited FVG to the nearest recent zone close to Entry; distant/old FVG is hidden.
- Kept Order Block visually behind the trade scenario and reduced label overlap.
- Made the scenario box narrower and added compact ENTRY / TP1 / SL labels inside the chart.
- Reworded the top Arabic activation message to avoid mixed RTL/LTR M5 rendering artifacts.
- Version bumped to 3.41.3.
