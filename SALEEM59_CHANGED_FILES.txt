SaleeM v3.51.0 — Animation Spec v1

Changed:
- app/engine/renderer.py: strict expected scenario path + public animation geometry.
- app/templates/index.html: SVG overlay canvas and replay control.
- app/static/app.js: synchronized SVG animation with chart pan/zoom.
- app/static/style.css: W/M, activation, zone, break/retest/continuation animation.
- app/__init__.py and app/main.py: version identifiers.
- tests/test_animation_v351.py: animation-plan and UI safeguards.
- docs/V351_ANIMATION_SPEC_V1.md: adopted implementation rules.

Rules:
- Original uploaded chart remains untouched as the visual base.
- Arrow appears for buy, sell, watch_buy and watch_sell when strict X/Y anchors exist.
- Path explains break -> retest -> continuation and is clipped before distant TP.
- X must come from calibrated screenshot candles; Y must come from strict pixel-axis mapping.
- W/M is the only pattern skeleton animated in v1.
- One main scenario only; no guessed geometry.
 geometry now use the calibrated candle-X map; if X cannot be trusted, the overlay is hidden.
- BOS/CHOCH now require a real swing level followed by an actual closing break; the line runs from the broken swing to the break candle.
- IDM is the last real internal opposite swing inside the BOS leg; it is not fabricated above/below the chart.
- OB and FVG rectangles now begin at their detected source candle X and keep their true price bounds.
- Confirmed patterns show Entry Zone, Neckline/Activation, Invalidation and a forecast arrow from the actual breakout candle to the measured pattern target.
- Original uploaded chart pixels remain unchanged; all drawings are overlays only.

SaleeM v3.45.0 — Anchored chart-pattern overlays
- Preserves the uploaded M5 screenshot pixel geometry; patterns are overlays only.
- Draws pattern geometry only when M5 candle X anchors are detected in the original screenshot.
- Candidate patterns use dashed boundaries and never receive a forecast arrow.
- Confirmed breakouts may draw one measured straight forecast arrow from the real activation level.
- Adds deterministic Triple Top/Bottom, Head & Shoulders / inverse, Rectangle, Flag and Pennant review, while retaining W/M, triangles, wedges and channels.
- At most two distinct M5 pattern families are drawn; higher-timeframe patterns stay in the fixed UI and are not guessed onto M5.
- BOS/CHOCH/IDM now use detected source-candle X anchors; labels may switch side but anchor dots do not move.

SaleeM v3.44.0 — Preserve uploaded chart + flatter fixed cards
- The result chart now uses the exact uploaded landscape screenshot as its base; candles and the source price axis are not regenerated.
- Axis geometry is extracted from the original landscape upload instead of converting it to the old portrait canonical viewport.
- S/R, zones, structure and valid trade guidance are lightweight overlays inside the pannable chart.
- Fixed information cards use flatter backgrounds, softer borders and smaller radii; the recommendation tile no longer looks like a raised button.
- Market-strength display falls back to the analysis probability when action strength is zero/missing.
