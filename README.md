# SaleeM v3.10.0

تطبيق FastAPI متخصص في تحليل صور شارت الذهب `XAUUSD` على فريم `M5`. يستخدم صورة المستخدم مرجعًا للسعر الحالي ومحور الأسعار، ويجلب بيانات `M5` و`M15` و`H1` و`H4` من Twelve Data، ثم يستخدم OpenAI لإرجاع تحليل منظم قبل رسم طبقات SaleeM فوق صورة الشارت الأصلية.

## آلية العمل

1. يرفع المستخدم صورة شارت الذهب M5 بصيغة PNG أو JPG أو WEBP، وبحجم أقصى 12 ميجابايت و40 مليون بكسل.
2. يحاول التطبيق اكتشاف صندوق الشارت وقصه مؤقتًا لتحسين قراءة السعر ومحور الأسعار. لا تُحفظ الصورة بعد انتهاء الطلب.
3. تُجلب بيانات السوق للفريمات الأربعة مع تخزين مؤقت مستقل لكل فريم.
4. يستخدم H4 للاتجاه العام، وH1 للبنية، وM15 للتفعيل، وM5 للتوقيت.
5. تُرسل صورة الشارت وملخص السوق ودستور SaleeM ومكتبة المعرفة إلى OpenAI بصيغة JSON Schema صارمة.
6. يراجع الكود النتيجة مرة أخرى: يطبّع الاحتمالات، يدمج المستويات، يقرر الحالة، ويصحح الدخول والوقف والأهداف.
7. يستخدم الرسم صورة الشارت الأصلية كخلفية، ثم يضيف محور SaleeM والبطاقات والمستويات والمناطق والجلسات.
8. تُعرض النتيجة في الصفحة كصورة قابلة للحفظ والمشاركة، مع نموذج تقييم منفصل.

## قواعد القرار الأساسية

- لا يوجد انحياز افتراضي إلى شراء أو بيع.
- أوزان الفريمات العليا أقوى من آخر حركة في M5.
- النتيجة تكون مراقبة عندما يكون الاتجاه غير واضح، أو الاحتمال أقل من 58٪، أو لا توجد نقطة تفعيل صالحة.
- الحالة المؤكدة تحتاج احتمالًا لا يقل عن 72٪، وتوافق H4 وH1، وتوافق فريمات 75٪ فأعلى، وهندسة صحيحة للوقف والأهداف، وعدم وجود تحذير في بيانات السوق.
- الوقف يكون خلف أقرب قاع/قمة أو مستوى إبطال، وبمسافة ديناميكية غالبًا بين 0.6 و4.0 دولار.
- الأهداف تُبنى أولًا من المستويات المقابلة، ثم من قيم النموذج، ثم من مضاعفات المخاطرة.

## متغيرات البيئة

انسخ `.env.example` إلى إعدادات Railway. المتغيران الإلزاميان:

```env
OPENAI_API_KEY=...
TWELVE_DATA_API_KEY=...
```

لا تضع المفاتيح الحقيقية داخل GitHub.

## التخزين المؤقت

القيم الافتراضية:

- M5: 240 ثانية.
- M15: 840 ثانية.
- H1: 3300 ثانية.
- H4: 14400 ثانية.

المسار الافتراضي مؤقت:

```env
MARKET_DATA_CACHE_PATH=/tmp/saleem_market_data_cache.json
SALEEM_FEEDBACK_STORE_PATH=/tmp/saleem_feedback_store.json
```

على Railway يُفضّل تركيب Volume على `/data` ثم استخدام:

```env
MARKET_DATA_CACHE_PATH=/data/saleem_market_data_cache.json
SALEEM_FEEDBACK_STORE_PATH=/data/saleem_feedback_store.json
```

## التشغيل المحلي

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

ثم افتح `/health` للتحقق من وجود إعدادات OpenAI وTwelve Data دون كشف المفاتيح أو عنوان البريد.

## قاعدة التحليل الدائمة

يحمّل التطبيق الملف `knowledge/09_rules/PERMANENT_ANALYSIS_PROMPT.md` داخل كل طلب تحليل تلقائيًا. تفرض القاعدة فحص سيناريو الصعود والهبوط بصيغة IF/THEN، وتحديد شرط الإلغاء، وأقوى الدعم والمقاومة، مع منع اختلاق أخبار أو بيانات DXY غير متوفرة.


## القالب البصري الموحّد v3.10

- `Entry` هي التسمية الوحيدة للدخول؛ لا تستخدم `Trigger` أو `Active`.
- بطاقات المحور اليميني تتحرك رأسيًا مع السعر، وتبقى خطوطها أفقية على موضع السعر الحقيقي.
- استبدل السهم بشموع سيناريو شبه شفافة تصل بالتتابع إلى TP1 وTP2 وTP3.
- أماكن التعليقات ثابتة لكل المستخدمين، ويتغير محتواها فقط.
