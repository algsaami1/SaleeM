# 10 — الرسومات المرجعية

رسومات SVG أصلية ومبسطة لاستخدامها كمرجع تعليمي داخل المشروع. ليست لنسخ الأسعار أو النتائج، بل لفهم الشكل العام للنمط.

## مكتبة صور المصادر — v3.61

- المجلد `source_models/raw/` يحتوي صور المصادر التي رفعها المستخدم (82 صورة).
- الملف `source_models/source_model_atlas.webp` أطلس مصغر يستخدم لمطابقة كل شارت جديد مع العائلات المرجعية.
- الملف `source_models/source_model_catalog.json` يربط كل عائلة بمرجعها وقاعدتها.
- المطابقة البصرية لا تكفي وحدها للرسم؛ يجب أن يؤكد محرك M5 الحتمي هندسة النموذج على شموع مغلقة.
- يرسم التطبيق النموذج الأقرب فقط، مع سهم متقطع للمرشح وسهم متصل للمؤكد.
