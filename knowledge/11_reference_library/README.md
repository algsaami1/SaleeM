# SaleeM Reference Library v1

هذه المكتبة هي الخلاصة التنفيذية للصور والفيديوهات المرجعية التي رفعها المستخدم.

- روجعت 107 ملفات فيديو MP4 حقيقية، منها 106 محتويات فريدة؛ متوسط الفيديو نحو 33 ثانية ومجموعها قرابة 59 دقيقة.
- روجعت 106 ملفات صور فعلية، وبعد إزالة التكرار بقي 94 محتوى بصريًا فريدًا.
- ملفات `__MACOSX/._*` استبعدت لأنها metadata وليست فيديوهات/صورًا إضافية.
- المكتبة لا تحفظ الفيديوهات الخام داخل منطق التحليل ولا تقارن الشكل بالعين فقط.
- كل مرجع حُوّل إلى شروط: بنية، pivots، كسر، إعادة اختبار، إبطال، دخول، وقف، هدف، وقواعد رسم.

## القاعدة الأساسية

المكتبة تعلم SaleeM **ما الذي يبحث عنه**، لكن OHLC الحقيقي هو الذي يقرر **هل النموذج موجود أم لا**.

النماذج التي لا يوجد لها detector حتمي في v3.52 تبقى `library_only_no_fabrication`، أي لا يرسمها التطبيق لمجرد أنها موجودة في المكتبة.
