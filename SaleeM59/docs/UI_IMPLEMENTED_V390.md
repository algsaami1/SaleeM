# واجهة SaleeM v3.9.0

تم تنفيذ إعادة ترتيب الواجهة فعليًا في ملفات التطبيق، وليس إضافتها كمقترح فقط.

## التغييرات

- استبدال صورة الرأس الكبيرة برأس صغير يحمل اسم SaleeM ورمز XAUUSD M5.
- جعل بطاقة رفع الصورة أقصر وأوضح.
- نقل تعليمات التقاط الصورة وشرح Exact Axis Mode إلى نافذة مساعدة.
- أثناء التحليل تظهر نسبة التقدم وقائمة المراحل فقط، وتختفي عناصر الصفحة الأخرى.
- عند ظهور النتيجة تكون صورة الشارت أول عنصر، ثم زرا الحفظ والمشاركة.
- إضافة شريط مختصر لنوع الصفقة والحالة والاحتمال.
- نقل تفسير النتيجة إلى قسم قابل للفتح بعنوان «لماذا ظهرت هذه النتيجة؟».
- تصغير التقييم والملاحظات، وجعل إحصاءات المشاركين قسمًا قابلًا للفتح.
- استبدال بطاقة «الجلسة» داخل صورة التحليل ببطاقة «نوع الصفقة».
- ألوان نوع الصفقة: بشرط برتقالي، مراقبة أزرق، شراء أخضر، بيع أحمر.
