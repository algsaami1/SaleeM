# SaleeM v3.13 — تحسينات الواجهة والنصوص

- ترتيب مراحل المعالجة: تحديث السوق، اتجاه الفريمات، الهيكل، الدعم والمقاومة، العرض والطلب، الزخم، السيناريو، ثم توليد الشارت.
- عدد المراحل ديناميكي في JavaScript؛ تتحرك علامة الإنجاز ونسبة التقدم عبر المراحل الثماني.
- مربع «النموذج» يدعم سطرين مع تصغير تلقائي للخط ويعرض «غير مكتمل» عند غياب النموذج.
- تكبير بسيط لرابط «تحليل صورة جديدة» في موضعه مع أيقونة صغيرة ومساحة ضغط أوضح.
- استبدال عنوان التحذير القديم بـ «اكتملت قراءة الصورة والتحليل».
- لا تظهر عبارة «الوضع الاحتياطي للقراءة» إلا عند فشل التحقق المباشر من المحور واستخدام القراءة الاحتياطية فعليًا.
- تعريب IF/THEN إلى «إذا/فإن» وتلوين الكلمتين بالأحمر داخل تفاصيل النتيجة مع تعقيم النص قبل عرضه.
- إعدادات البريد مؤجلة ولم تُعدّل في هذا الإصدار.
