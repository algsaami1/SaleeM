# SaleeM v3.63 — Static Reference Overlay

## القاعدة المعتمدة

1. لا GIF ولا زر تشغيل ولا حركة تلقائية داخل الشارت.
2. صورة الشارت التي يرفعها المستخدم تبقى الخلفية الأصلية نفسها.
3. عند الرفع، تُعرض الصورة داخل مربع الشارت نفسه فقط باستخدام `object-fit: contain`.
4. بعد التحليل تستبدل واجهة الرفع بواجهة النتيجة.
5. يراجع النظام صورة الشارت مع أطلس صور المصادر المعتمدة.
6. يختار عائلة نموذج واحدة هي الأقرب بصريًا، ثم لا يقبلها للرسم إلا بعد تحقق هندسة M5 المغلقة.
7. النموذج المرسوم يثبت على قمم/قيعان/عنق/حدود حقيقية فقط.
8. النموذج المرشح: خطوط وسهم توقع متقطعان.
9. النموذج المؤكد: خطوط وسهم توقع متصلان.
10. لا يوجد سهم عام أو تخميني عند عدم وجود نموذج مرجعي صالح.
11. الشارت الرئيسي يبقى خفيفًا: أقرب S/R أو منطقة قرار + النموذج الأقرب وسهمه فقط، دون طبقات عامة تزدحم فوق الشموع.
12. شرح «القاعدة الأساسية» يبقى أسفل صورة الحفظ/المشاركة.

## الواجهة

- حُذف شريط التنقل السفلي من شاشة النتيجة.
- صُغرت بطاقات القراءة العلوية والسفلية وثُبتت داخل Grid لمنع الانزياح الأفقي.
- ألوان الحالات لم تتغير: شراء أخضر، بيع أحمر، مراقبة أزرق، مشروط برتقالي.
- في واجهة رفع الشارت فقط، الأزرار/العناصر الحمراء الخاصة بالرفع أصبحت خضراء.
