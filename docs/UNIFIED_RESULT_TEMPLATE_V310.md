# قالب نتيجة SaleeM الموحّد — v3.10.0

تم اعتماد القواعد التالية داخل محرك الرسم:

- أربع بطاقات علوية ثابتة: الحالة، النموذج، الاحتمال، نوع الصفقة.
- لا توجد بطاقات نصية للسيناريو داخل الشارت؛ تُحفظ السيناريوهات وشروطها ضمن بيانات التحليل فقط.
- Entry بدل Trigger وActive.
- بطاقات المحور اليميني تتحرك رأسيًا حسب السعر الحقيقي، والخط الواصل أفقي تمامًا على السعر.
- التداخل بين البطاقات يعالج بالحركة الأفقية فقط.
- لا يوجد سهم توقع؛ توجد شموع سيناريو شبه شفافة تبدأ من Entry وتصل إلى TP1 ثم TP2 ثم TP3.
- الشارت ومحوره الأصليان لا يتحركان ولا يعاد رسمهما.
