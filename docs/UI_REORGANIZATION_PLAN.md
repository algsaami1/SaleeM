# خطة ترتيب واجهة SaleeM

## المشكلة الحالية

الصفحة الرئيسية تعرض قبل النتيجة: صورة علوية كبيرة، بطاقة الرفع، المميزات، وشرحًا تقنيًا طويلًا للمحور. وبعد التحليل تعرض الصورة، الملاحظات، تنبيه النسخة التجريبية، التقييم، ملخص المشاركين، ثم الملاحظات. هذا يجعل أهم عنصر — صورة التحليل — وسط صفحة طويلة.

## الترتيب المقترح

### الصفحة الرئيسية

1. رأس مختصر يحمل شعار SaleeM وحالة الخدمة فقط.
2. بطاقة رفع واحدة كبيرة.
3. زر صغير «كيف ألتقط صورة صحيحة؟» يفتح تعليمات مختصرة.
4. رابطان أسفل الصفحة: «كيف يعمل التحليل؟» و«الخصوصية».

يُنقل شرح Exact Axis Mode وReset Vertical Scale من الصفحة الرئيسية إلى نافذة المساعدة، ولا يظهر إلا عند فشل المحور.

### أثناء التحليل

- إخفاء بطاقات المميزات والتنبيهات.
- إبقاء دائرة التقدم وقائمة المراحل فقط.
- عدم عرض مدة ثابتة إذا لم تكن مقاسة من الخادم.
- جعل المراحل مرتبطة مستقبلًا بأحداث حقيقية بدل تقدم زمني تقديري فقط.

### صفحة النتيجة

1. صورة التحليل مباشرة في أعلى الصفحة.
2. زران واضحان: حفظ الصورة ومشاركتها.
3. شريط مختصر: نوع الصفقة، الحالة، الاحتمال، ومصدر السعر.
4. قسم قابل للفتح «لماذا ظهرت هذه النتيجة؟» وفيه اتجاه H4/H1/M15/M5 وشرط التفعيل.
5. نموذج تقييم مختصر.
6. الملاحظات والاقتراحات داخل نافذة منفصلة.
7. ملخص المشاركين يُنقل إلى صفحة «إحصاءات النسخة التجريبية» بدل عرضه بعد كل تحليل.

## البطاقة العلوية داخل صورة النتيجة

وفق آخر قرار واجهة مطلوب، البطاقة التي تحمل «الجلسة» يجب أن تتحول إلى «نوع الصفقة»:

- بشرط: برتقالي.
- مراقبة: أزرق.
- شراء: أخضر.
- بيع: أحمر.

الجلسة لا تظهر في هذه البطاقة؛ يمكن إبقاؤها في شريط الجلسات أسفل الصورة. هذا التغيير لم يُطبق في نسخة التنظيف حتى لا نغير التصميم قبل اعتماد الترتيب النهائي.

## شروحات آلية العمل للمستخدم

يُفضّل تقديمها في ثلاث طبقات:

- شرح سريع: «الصورة للسعر والمحور، وبيانات السوق للاتجاه والفريمات».
- شرح متوسط قابل للفتح: خطوات التحليل الأربع.
- شرح تقني منفصل: Exact Axis Mode، التخزين المؤقت، ومصادر البيانات.

## أول تعديل واجهة موصى به

ابدأ بإعادة ترتيب HTML فقط مع الحفاظ على نفس CSS والمنطق: ضع النتيجة والإجراءات أولًا عند وجود تحليل، وأخفِ المميزات والشرح التقني في صفحة النتيجة. هذا تعديل منخفض المخاطر ويمكن اختباره قبل تغيير رسم الشارت.
