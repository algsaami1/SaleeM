# تثبيت بطاقات الأسعار على موضعها الحقيقي

تم إلغاء أي توزيع رأسي لتسميات الدعم والمقاومة، وأصبحت القاعدة موحدة:

- كل سعر يُحوّل مرة واحدة عبر دالة `price_to_y` المشتركة.
- مركز بطاقة Entry / Stop / Cancel / TP يساوي موضع السعر نفسه.
- مركز تسمية R1 / R2 / S1 / S2 يساوي موضع خط المستوى نفسه.
- يسمح بالتداخل الرأسي بين البطاقات والتسميات.
- لا يُسمح بأي إزاحة رأسية مستقلة لتجنب التداخل.
- الإزاحة الأفقية فقط مسموحة، ولا تغيّر السعر الذي يمثله العنصر.
