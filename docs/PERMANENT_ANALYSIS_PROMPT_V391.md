# قاعدة التحليل الدائمة — SaleeM v3.9.1

تم تحويل البرومبت الموجود في الفيديو إلى قاعدة فعلية تُحقن تلقائيًا داخل كل طلب تحليل.

## ما يطبق في كل تحليل

- الأصل ثابت: XAUUSD.
- تحليل تعليمي وليس توصية مالية.
- أسلوب سكالب قصير المدى.
- H4 للاتجاه، H1 للبنية، M15 للتفعيل، M5 للدخول.
- فحص سيناريو صعود وسيناريو هبوط بصيغة عربية «إذا/فإن».
- اختيار السيناريو الأعلى احتمالًا فقط للرسم.
- إظهار السيناريو البديل في تفاصيل النتيجة أسفل الصورة.
- تحديد شرط إلغاء واضح.
- أقوى دعمين ومقاومتين، والدخول والوقف وثلاثة أهداف.
- عدم اختلاق أخبار أو أثر للدولار عندما لا توجد بيانات أخبار أو DXY ضمن المدخلات.
