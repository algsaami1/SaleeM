# SaleeM v3.62 — Light Four-Color UI

هذا التحديث بصري في الأساس، ولا يغيّر منطق التحليل أو قواعد اختيار النموذج أو رسم الشارت.

## النظام البصري المعتمد

- الأخضر: شراء / إيجابي.
- الأحمر: بيع / سلبي، وهو أيضًا لون الهوية والإجراء الرئيسي.
- الأزرق: مراقبة / معلومات / معالجة.
- البرتقالي: مشروط / انتظار تفعيل.
- الخلفية: رمادي فاتح جدًا.
- البطاقات: بيضاء، حواف دائرية، ظل خفيف وحدود رفيعة.

## التغييرات

1. تحويل الشعار والإجراءات الرئيسية إلى الهوية الحمراء.
2. صفحة الرفع أصبحت أبسط وأكثر قربًا من تصميم تطبيقات الهاتف الحديثة.
3. إضافة شريط واضح للحالات الأربع دون أرقام مصطنعة.
4. جعل حالة `conditional` تظهر «مشروط» بالبرتقالي بدل دمجها بصريًا مع «مراقبة».
5. تحويل شاشة النتيجة من المظهر الداكن إلى بطاقات فاتحة مع إبقاء الشارت الأصلي كما هو.
6. الحفاظ على وظائف Zoom/Pan والـOverlay والأنيميشن دون تغيير.
7. إضافة تنقل سفلي خفيف للرئيسية/النتيجة أو التحليل/التفاصيل.
8. إبقاء لوحة حالة النظام الإدارية داكنة لأنها سطح إدارة منفصل.

## ما لم يتغير

- قواعد التحليل.
- مطابقة صور النماذج المرجعية.
- قواعد الأسهم والخطوط فوق الشارت.
- مستويات الدخول/الإلغاء/الأهداف.
- البيانات ومصدر Twelve Data.
